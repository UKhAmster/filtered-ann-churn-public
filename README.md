# Filtered ANN under data churn

Artifacts for the preprint *Mechanism-Dependent Degradation of Filtered Approximate Nearest
Neighbor Indexes under Data Churn* (V. Asonov, HSE University, 2026): the evaluation protocol,
drivers for four filtered ANN methods, the scripts that produce every table and figure, and the
raw per-checkpoint results.

The protocol replays a stream of deletions and insertions against a filtered index and, at every
checkpoint, compares the index answers with exact filtered top-k of the live collection. It
reports recall@10 (mean, 5th percentile, share of queries below 0.9) and the number of distance
computations per query, so that work is comparable across machines.

## Layout

```
src/fanndyn/      Python package: data readers, scenarios (runbook), exact ground truth, metrics
adapters/         one Docker image per method, C++ drivers speaking adapters/common/fanndyn_io.h
                    hnswlib, filtered_diskann (Filtered-DiskANN), ung (UNG), acorn (ACORN)
scripts/          experiment drivers, aggregation, laws and figures
results/          raw results: CSV per checkpoint, JSON run configs, driver logs
paper/            preprint source, figures and PDF
docs/             capability map of the methods (insert / delete / update support)
tests/            unit tests of the package
```

Method revisions are pinned by commit SHA in each `Dockerfile` (`ARG COMMIT_SHA`).
Code comments and the READMEs inside `adapters/` and `results/yfcc/` are in Russian.

## Setup

Python 3.11+ and Docker are required.

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
make test

bash adapters/smoke.sh acorn      # base image fanndyn-acorn:smoke for the ACORN driver
cd adapters
docker build -f hnswlib/Dockerfile.driver          -t fanndyn-hnswlib:driver .
docker build -f filtered_diskann/Dockerfile.driver -t fanndyn-filtered_diskann:driver .
docker build -f ung/Dockerfile.driver              -t fanndyn-ung:driver .
docker build -f acorn/Dockerfile.driver            -t fanndyn-acorn:driver .
```

## Data

- **SIFT1M** (`sift_base.fvecs`, `sift_query.fvecs`) in `~/data/sift`, with synthetic Zipf or
  k-means labels generated by the drivers.
- **YFCC-10M** from the filtered track of big-ann-benchmarks (NeurIPS'23): a 1M prefix of the base
  vectors and tags is fetched with HTTP range requests, together with the public queries:

  ```bash
  python3 scripts/fetch_yfcc.py --n 1000000 --out ~/data/yfcc
  ```

## Running

```bash
# one trajectory: method x scenario x maintenance mode
.venv/bin/python scripts/pilot_driver.py --dataset yfcc --method hnswlib --scenario steady_churn --mode mark
.venv/bin/python scripts/pilot_driver.py --method diskann --scenario steady_churn --mode lazy

# ranges across seeds
.venv/bin/python scripts/aggregate_seeds.py results/yfcc/churn_3x results/yfcc/churn_3x_seed8 results/yfcc/churn_3x_seed9

# figures of the preprint
.venv/bin/python scripts/preprint_figures.py paper/figures
```

`--help` of each script lists the parameters; the values used in each run are stored in the JSON
next to its CSV in `results/`. The filters chosen on YFCC and the operating points are described
in `results/yfcc/README.md`.

## Testbed

All numbers were measured on a single virtual machine: 8 vCPU pinned to one NUMA node of an
AMD EPYC 9754 host, 16 GB RAM without ballooning, SATA SSD, Ubuntu 24.04, GCC 13.3, Docker 29.
Runs are sequential. Latency depends on the machine; distance computations per query do not.
